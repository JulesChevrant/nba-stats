# NBA – Résultats

Page web perso pour suivre les résultats NBA d'un coup d'œil : scores, stats principales des joueurs (minutes, points, rebonds, passes, interceptions, contres, +/-) et classement par conférence.

**Site en ligne :** https://juleschevrant.github.io/nba-stats/

## Fonctionnement

- Un seul fichier `index.html`, sans installation ni serveur.
- Les données sont récupérées en direct dans le navigateur depuis l'API publique non officielle d'ESPN.
- Les matchs en cours se rafraîchissent automatiquement toutes les 30 secondes.
- Pensée pour mobile (ajout possible à l'écran d'accueil, icône `apple-touch-icon.png`).

## Mettre à jour

Modifier `index.html`, puis `git add`, `git commit` et `git push` : GitHub Pages republie le site en une à deux minutes.

## Avertissement

Projet personnel, sans lien avec la NBA ni ESPN. Les données proviennent d'une API non documentée, qui peut changer ou cesser de fonctionner sans préavis.
